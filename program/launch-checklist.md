# Launch Checklist
 
A pre-launch readiness checklist for program owners preparing to onboard their first champion cohort. Complete every item before announcing the program or recruiting champions. Skipping items here creates problems that are much harder to fix after champions are onboarded.
 
---
 
## Organizational Readiness
 
- [ ] Executive sponsor identified and charter signed
- [ ] Engineering leadership briefed (Directors/VPs covering target teams)
- [ ] HR notified of program (especially if belt levels will connect to career frameworks)
- [ ] Manager briefing sessions completed for all managers of target cohort
- [ ] Manager commitment forms signed for all target cohort managers
- [ ] Legal or compliance notified if program touches regulated data handling workflows
---
 
## Program Infrastructure
 
- [ ] Champion community channel created and tested
- [ ] Scanner dashboard access provisioned for champion scope (confirm access controls)
- [ ] Training platform access provisioned for initial cohort
- [ ] Program documentation published and accessible (charter, roles doc, playbooks, onboarding guide)
- [ ] Belt progression criteria documented and accessible to champions and managers
- [ ] Risk register or tracking system configured for accepted risk documentation
---
 
## Champion Cohort
 
- [ ] Initial cohort of 10–15 champions identified using qualification criteria
- [ ] All nominees confirmed to meet qualification criteria (technical reach, peer respect, curiosity, bandwidth)
- [ ] All nominees have confirmed acceptance (voluntary — not assigned)
- [ ] Manager approval documented for every champion in cohort
- [ ] Buddy assignments made (pair new champions with existing champions where available; Security team serves as buddy for first cohort)
- [ ] Welcome emails sent with access confirmation instructions
- [ ] First meetup scheduled and calendar invites sent
---
 
## Metrics Baseline
 
- [ ] Baseline vulnerability counts captured for target teams (for MTTR and DER comparison)
- [ ] Scanner baseline established (current open finding counts by severity)
- [ ] Manager feedback baseline survey sent (pre-program workload and sentiment)
- [ ] Metrics tracking system configured for Phase 1 KPIs
---
 
## Communication Plan
 
- [ ] All-hands announcement prepared and scheduled (with executive sponsor involvement)
- [ ] Champion channel announcement post drafted
- [ ] Manager communication (post-launch update to participating managers) drafted
- [ ] First monthly meetup agenda drafted
- [ ] Quarterly spotlight template prepared for end of first quarter
---
 
## Security Team Readiness
 
- [ ] Security team capacity confirmed to support initial cohort (triage guidance, training, meetups)
- [ ] Security team contact assigned to each champion for first 90 days
- [ ] First triage assignments prepared for Week 2 of onboarding
- [ ] Training content reviewed and ready for delivery
- [ ] Escalation path confirmed and documented for champion use
---
 
**Launch gate:** All items above must be checked before the first champion is onboarded. If items are incomplete, identify an owner and a completion date before proceeding.
