# Manager Kudos Templates
 
Ready-to-send recognition templates for managers to share champion contributions with their director or skip-level. Managers should personalize these — but having a template removes the blank-page friction that causes recognition to not happen at all.
 
---
 
## Template 1: First Contribution
 
**Subject:** [Champion name] — Security Champion contribution
 
Hi [Director name],
 
I wanted to share a quick update on [Champion name]'s participation in the Security Champions program.
 
This month, [he/she/they] completed [his/her/their] first security triage work and [specific contribution — e.g., "identified and documented three medium-severity vulnerabilities in our authentication flow before they reached production"]. The Security team confirmed the quality of the work was strong.
 
I am glad we invested in nominating [him/her/them] for this program. Happy to share more at our next 1:1.
 
[Manager name]
 
---
 
## Template 2: Quarterly Impact Update
 
**Subject:** [Champion name] — Security Champion Q[X] update
 
Hi [Director name],
 
A quick quarterly update on [Champion name]'s Security Champion work.
 
This quarter:
- Triaged [X] security findings for our team, resolving [Y] before they reached production
- Published [Z] security SOPs now being used across [X] teams
- Participated in [threat model / security review / other activity] for [feature name]
The Security team flagged [his/her/their] work as a strong contributor to [metric — e.g., "our team's improved MTTR on security findings"]. I wanted to make sure this is visible above the team level.
 
[Manager name]
 
---
 
## Template 3: Belt Promotion
 
**Subject:** [Champion name] promoted to [Belt] Champion
 
Hi [Director name],
 
[Champion name] was promoted to [Green/Blue/Brown/Black] belt in the Security Champions program this week.
 
[He/She/They] earned this by [specific criteria — e.g., "completing all required training, triaging over 20 findings in the past quarter, and creating three SOPs now used across our team"].
 
This level of technical investment and security ownership is exactly what I want to encourage on our team. Wanted to make sure you heard about it.
 
[Manager name]
 
---
 
## Template 4: Program Defense (for managers facing pushback from their own leadership)
 
**Subject:** Security Champions — context for [skip-level name]
 
Hi [Skip-level name],
 
I wanted to give you some context on [Champion name]'s participation in the Security Champions program in case it comes up.
 
The time investment is approximately [X] hours per week. In return, our team has seen [specific outcome — e.g., "a 30% reduction in security findings reaching the QA stage, and zero security-related release blocks this quarter"].
 
More importantly, [Champion name] is developing skills that make the whole team ship better code — not just the security pieces. I consider this a strong ROI on the time we are investing.
 
Happy to discuss further.
 
[Manager name]
